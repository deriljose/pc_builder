# 💻 PC Builder – Gemini-Powered PC Build Suggestion Tool

**PC Builder** is an intelligent, Gemini-powered web application that helps users build custom PC configurations without requiring technical expertise. Users can generate optimized PC part lists based on their preferences, gaming needs, and performance goals. The tool also features a chatbot to answer PC-related questions and provides deep insights into hardware compatibility and performance.

This project was done as part of our S6 Mini Project.

## 🚀 Features

1. **Non-Technical Guided Recommendations**  
   Users answer a series of simple, non-technical questions. Based on these answers, the system suggests a complete PC parts list optimized for their needs.

2. **Bottleneck Calculator**  
   Automatically analyzes and reports potential bottlenecks between CPU and GPU in the recommended build, ensuring optimal performance balance.

3. **Performance & Benchmarks**  
   Provides real-world performance metrics and benchmark scores for the generated PC configuration.

4. **Game-Based Build Suggestions**  
   Users can select specific games they intend to play, and the tool will recommend PC parts that deliver the best performance for those titles.

5. **AI Chatbot**  
   An integrated chatbot, powered by Gemini, is available to answer general PC building questions, part compatibility issues, and offer personalized advice.

## 🛠 Tech Stack

- **Frontend:** HTML, CSS  
- **Backend:** Node.js  
- **Database:** MongoDB  
- **AI Integration:** Gemini API (for chatbot and smart suggestions)
